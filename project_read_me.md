# Apple iPhone Sales Analysis in India (2020–2026)

## 📌 Executive Summary
This project delivers a comprehensive, multi-tool data science and business intelligence audit tracking Apple iPhone shipments, market expansion, and future demand in India from 2020 to 2026. The analysis bridges raw market data with relational database architecture, exploratory data analysis (EDA), machine learning forecasting, and an executive Power BI dashboard.

---

## 🛠️ Tech Stack & Tools
- **Spreadsheets:** Microsoft Excel (Financial metrics, CAGR, YoY growth calculations)
- **Database:** MySQL Workbench (Relational schema, complex queries, CTEs, window functions)
- **Programming Languages:** Python 3 (Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Statsmodels)
- **Business Intelligence:** Power BI Desktop (4-page executive dashboard with custom KPI cards and filters)
- **Version Control:** Git & GitHub

## 📊 Key Findings & Metrics
- **Explosive Market Growth:** Shipments scaled from **3.2 Million units in 2020 to 14.0 Million units in 2025**, representing an overall growth of **337.50%**.
- **Compound Annual Growth Rate (CAGR):** Achieved a strong 5-year CAGR of **34.34%** (2020–2025).
- **Future Projections:** Machine learning models (Linear Regression & Holt Exponential Smoothing) forecast shipments to reach approximately **18.17 Million units by 2027**.
